## **Aegis – Telecom Alert System**  
*June 2026 – July 2026 | Personal Project*

A robust event-driven alert system designed to monitor and assess risks for telecom stations in real-time.

- **GIS & Event-Driven**: Served spatial mapping data for 10,000 telecom stations under 12ms using PostgreSQL/PostGIS and Redis. Decoupled STOMP map updates from Telegram alerts via ActiveMQ.
- **Risk Engine**: Automated weather forecasts and disaster geofencing. Implemented multi-factor risk quantification and automated SLA escalations.
- **SRE & Observability**: Provisioned infrastructure via Terraform and Ansible. Validated peak throughput of 2,150 req/s using k6, and set up Prometheus, Loki, and Tempo.
- **Key Technologies**: Java 21, Spring Boot 3, PostgreSQL/PostGIS, Redis, ActiveMQ Classic, Next.js, Terraform, Ansible, Prometheus, Loki, Tempo, Docker, k6.
